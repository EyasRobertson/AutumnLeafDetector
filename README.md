App created with JavaFX. It takes in a user supplied picture, then identifies any autumn leaves in the image. 
A black and white copy of the image is created and the user can then interact with it.
The user can change how the image is processed to get a better black and white version.
The user can click on a leaf and change it to a random colour. Random colours can be applied to every leaf.
The leaves can be numbered based on pixel count. 
An estimate of the number of leaves can be given
